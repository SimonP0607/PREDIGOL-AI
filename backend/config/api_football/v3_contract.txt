D This endpoint returns in-play odds for fixtures in progress.

D `* This value can change in the range of 5 to 60 seconds`

D ```

D "blocked": false, // True if bets on this fixture are temporarily blocked
D "finished": false // True if the fixture has not started or if it is finished
D },
D ```

D The `main` field will be set to `True` only if several identical values exist for the same bet.
D When a value is unique for a bet the `main` value will always be `False` or `null`.
D **Example below** :
D ```
D "id": 36,
D "name": "Over/Under Line",
D "values": [
D {
D "value": "Over",
D "odd": "1.975",
D "handicap": "2",
D "main": true, // Bet to consider
D "suspended": false // True if this bet is temporarily suspended
D },
D {
D "value": "Over",
D "odd": "3.45",
D "handicap": "2",
D "main": false, // Bet to no consider
D "suspended": false
D },
D ]
D ```
